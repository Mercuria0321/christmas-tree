# 星尘圣诞树 · Merry Christmas

一个原创的 Three.js 粒子圣诞树页面，灵感来自 [AnxForever/Christmas](https://github.com/AnxForever/Christmas)，场景、粒子和交互均为独立实现。

## 启动

1. 双击 `start.bat`
2. 浏览器会自动打开 [http://127.0.0.1:8777/](http://127.0.0.1:8777/)

需要安装 Python 3。three.js 与后期处理依赖已放在 `vendor/` 中，无需 `npm install`。

> 请通过本地服务器访问，不要直接双击 `index.html`：ES Module 与纹理加载在 `file://` 下会被浏览器拦截。

## 玩法

| 操作 | 效果 |
| --- | --- |
| 拖拽 | 旋转圣诞树 |
| 滚轮 | 缩放视角 |
| 底部「圣诞树」 | 24000 颗粒子组成的圣诞树，含灯串、彩球、雪花与星空 |
| 底部「星尘」 | 粒子散开成星云，装饰球一起飘散 |
| 底部「祝福」 | 粒子聚成祝福文字，输入中文或英文后点「点亮祝福」或按回车 |
| 底部「照片」 | 上传照片，照片会环绕圣诞树；点击照片进入聚焦查看 |
| 底部「手势」 | 开启摄像头手势控制（首次使用需联网加载模型） |
| 快捷键 `1` `2` `3` | 切换圣诞树 / 星尘 / 祝福 |
| 快捷键 `H` | 隐藏 / 显示界面 |
| `Esc` | 退出照片聚焦 |
| `←` `→` | 聚焦时切换照片 |
| `Enter` | 应用祝福文字 |

祝福文字最多 24 个字符；输入中文时副标题会自动变为 `MERRY CHRISTMAS`，输入英文时显示「圣 诞 快 乐」。

照片只在浏览器本地读取和显示，不会上传到任何服务器。

## 手势控制（可选）

点击「手势」并允许摄像头权限，将手伸向镜头，保持手势约 0.7 秒：

- 握拳 → 圣诞树
- 张开五指 → 星尘
- 剪刀手 / V 手势 → 祝福文字
- 食指向上指 → 聚焦照片（需先添加照片）

手势识别使用 MediaPipe Tasks Vision，从 CDN 加载 wasm 与模型，因此需要网络；普通 3D 场景完全离线可用。推荐 Chrome / Edge，并允许 `http://127.0.0.1` 使用摄像头。

## 技术要点

- Three.js r160，本地 ES Module + import map
- 自定义 GLSL 粒子着色器（逐粒颜色、尺寸、闪烁相位）
- UnrealBloom 泛光 + ACES 色调映射
- 粒子形态插值：圣诞树 / 星云 / 文字 / 聚焦
- Canvas 采样生成中文/英文粒子文字
- MediaPipe HandLandmarker 手势识别，按需懒加载
